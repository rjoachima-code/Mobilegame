# 🎮 JACAMENO - Beta Testing Quick Start

**Version 0.9.0** | Status: Ready for Beta Testing

## Try It Now! (Web Version)

The easiest way to test JACAMENO is through the web version:

```bash
cd web
python3 -m http.server 8000
# Open http://localhost:8000 in your browser
```

Or simply open `web/index.html` in any modern browser!

## What's New in This Version

### ✨ New Features
- **High Score System**: Your best score saves automatically
- **Sound Effects**: Audio feedback for all game actions
- **New High Score Celebration**: Special animation when you beat your record
- **Enhanced UI**: Beautiful gradient backgrounds and smooth animations

### 🎯 What Works
- ✅ Full Tetris gameplay (7 piece types)
- ✅ M2 Block merge mechanics (2→4→8→16...)
- ✅ Score, level, and line tracking
- ✅ Keyboard controls (Arrow keys, WASD, Space)
- ✅ Touch controls (swipe and tap)
- ✅ Pause/Resume
- ✅ Responsive design (works on mobile)
- ✅ High score persistence

### 🔧 Known Limitations
- No power-ups yet
- No background music (only sound effects)
- No settings menu
- No achievements
- No online leaderboard

## Quick Test Guide

1. **Start the game** - Click "Start Game"
2. **Play for 5 minutes** - Try to clear some lines
3. **Test controls** - Try keyboard AND touch (if mobile)
4. **Check high score** - Play again and try to beat it
5. **Report issues** - Use our bug report template

## Quick Controls Reference

### Keyboard
- **←/→ or A/D**: Move left/right
- **↓ or S**: Soft drop
- **↑ or W**: Rotate
- **Space**: Hard drop
- **P or ESC**: Pause

### Touch
- **Swipe left/right**: Move piece
- **Swipe down**: Hard drop
- **Tap**: Rotate piece
